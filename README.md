# mac-arrow

한 Mac의 왼쪽으로 쏜 화살을 상대 Mac 화면의 오른쪽에서 날아오게 하는 작은 macOS 도구입니다.

## 설치

상대방은 다음 한 줄로 설치합니다.

```bash
brew install ddingddong9/mac-arrow/mac-arrow
```

## 사용

먼저 두 화면의 위치를 macOS 디스플레이 설정처럼 배치합니다. 기본값은 `2 친구`가 왼쪽, `1 나`가 오른쪽입니다. 친구 화면을 선택해 `friends-mac.local` 대신 실제 호스트명이나 IP를 입력하고 저장하세요. `+ 친구 화면 추가`로 여러 명을 배치할 수 있습니다.

```bash
mac-arrow setup
```

상대방 Mac에서 수신기를 켭니다.

```bash
mac-arrow receive
```

수신기를 켜면 macOS 상단 메뉴바에 `🏹` 아이콘이 생깁니다. 메뉴에서 **궁수 생성**을 누르면 화면 오른쪽 아래에 졸라맨 궁수가 나타납니다. 활은 마우스를 따라 조준하며, 궁수 영역에서 누른 채 조준 반대쪽으로 당겼다가 놓으면 해당 방향에 배치된 친구에게 발사합니다.

배치도에서 내 화면이 오른쪽이면 궁수는 오른쪽 아래에서 왼쪽을 바라보고, 내 화면이 왼쪽이면 왼쪽 아래에서 오른쪽을 바라봅니다. 여러 친구가 양쪽에 있으면 친구 화면들의 평균 위치를 기준으로 배치됩니다.

- `궁수 생성/숨기기`: 졸라맨 궁수 표시 전환
- `화면 배치…`: 친구 화면 위치와 호스트 편집
- `모든 화살 지우기`: 화면에 꽂힌 화살 초기화
- `mac-arrow 종료`: 수신기와 궁수 종료

보내는 Mac에서는 배치 방향으로 발사합니다. 해당 방향에서 가장 가까운 화면이 자동 선택됩니다.

```bash
mac-arrow shoot left
# 높이 지정: 화면 아래 0.0, 위 1.0
mac-arrow shoot left --y 0.65
```

호스트를 직접 지정하는 기존 방식도 계속 사용할 수 있습니다: `mac-arrow shoot friends-mac.local`.

처음 수신할 때 macOS가 네트워크 연결 허용 여부를 물으면 허용해야 합니다. 방화벽을 사용하는 경우 UDP `45678` 포트를 허용하세요.

화면 효과만 미리 볼 수도 있습니다.

```bash
mac-arrow demo
```

## 로컬 개발

```bash
swift test

```

## 현재 범위

- 같은 Wi-Fi/LAN에서 IP 또는 `*.local` 호스트명으로 연결
- 화면 카드를 드래그해 2명 이상 배치하고, 방향별로 가장 가까운 친구를 자동 선택
- 메뉴바에서 졸라맨 궁수를 생성하고 마우스로 조준·당기기·놓기 발사
- 오른쪽 화면 가장자리에서 화살이 날아와 꽂힌 뒤, 수신기를 종료할 때까지 그대로 남는 투명 오버레이
- `--y`로 발사 높이 전달

전역 단축키, 자동 상대 검색, 인터넷 원격 연결은 다음 단계로 추가할 수 있습니다.
