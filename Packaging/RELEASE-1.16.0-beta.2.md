# SIU 1.16.0-beta.2 — 2대2 무응답 강제 종료 제거

- 2대2에서 8초 무응답만으로 참가자를 끊고 경기를 중단하던 처리를 제거했습니다. 메뉴/대화상자/일시적인 Wi-Fi 지연이 전체 경기 종료로 이어지지 않습니다.
- 경기·통신 타이머를 common run-loop mode에 등록해 일반 메뉴 조작 중에도 진행할 수 있도록 변경했습니다.
- 실제 TCP 연결 종료(EOF), 통신 오류, 잘못된 패킷은 기존처럼 감지하고 경기를 중단합니다. 무응답만으로는 끊지 않으므로 죽은 연결의 감지는 운영체제 TCP 처리에 따라 늦어질 수 있습니다.
- 방장은 0.5초 이상 오래된 이동 입력을 정지 입력으로 바꾸는 보호를 유지합니다. 끊긴 입력 때문에 선수가 계속 달리지는 않습니다.
- 메시팀·진영 선택·스태미나·슬라이딩 태클·자동 업데이트는 유지됩니다. 프로토콜은 1대1 13 / 2대2 3 그대로입니다. 모두 최신 패치로 업데이트를 권장합니다.

검증: 8.3초간 타이머가 동작하지 않는 run-loop 모드에서 대기한 뒤 4인 연결/경기 유지 확인. 실제 참가자가 나갔을 때 경기 중단 회귀 테스트, 기존 물리·진영·패스·업데이트 검증, 유니버설 앱 빌드 및 코드서명 검증. 다른 Mac 4대 와이파이 대전은 별도 실기기 검증 필요.

1.16.0-beta.1 사용자는 앱을 다시 열고 업데이트 팝업에서 ‘업데이트 후 재실행’을 선택할 수 있습니다. Homebrew로도 업데이트 가능합니다.

```bash
brew update
brew upgrade --cask ddingddong9/siu/siu-app-beta
```
