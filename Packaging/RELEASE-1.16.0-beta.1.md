# SIU 1.16.0-beta.1 — 메시팀·진영 선택·앱 자동 업데이트

- 사용자 제공 메시 사진/GIF의 원본 픽셀로 기본 1, 슛 23, 태클 20, 팬텀 7 투명 프레임 추출. 사용자가 사용·공개 배포 권한 확보 확인.
- 1대1 홈 대기 화면 진영 선택: 호날두팀/메시팀. 선택은 상대와 반대 진영으로 동기화되고 방장이 경기 시작. AI 연습 상대도 메시.
- 2대2 대기 진영 선택: 팀당 2명 유지. 빈 상대 슬롯 우선 교환, 전원 접속 시 상대팀 한 명과 교환. 모든 참가자에 진영 전달. 시작·득점 리셋에도 선택 유지. 패스 대상·태클 아군 판정·공격 방향을 선택 팀 기준으로 변경.
- 메시 슛(D), 태클(A), 팬텀(1대1 X / 2대2 Shift+A). 2대2 팬텀은 짧은 옆 방향 회피. 개인기 키는 SIU 간소화 입력.
- 자료가 없는 걷기/달리기·세레머니·발재간·백숏·사포는 메시 기본 자세/공 효과 사용. 호날두 영상으로 캐릭터를 바꾸지 않음. 원본 크롭·블러·가림은 남을 수 있음. 팬텀은 상대와 겹치지 않는 앞 구간만 사용.
- 앱 실행 직후 GitHub 새 릴리스 확인. 팝업 ‘업데이트 후 재실행’ → ZIP 다운로드 → SHA256/앱 식별자/버전/코드서명 검증 → 종료 → 앱 교체 → 재실행. 경기 중에는 보류. 취소 시 다음 실행에서 다시 안내.
- 설치 폴더 쓰기 권한 필요. 기존 앱은 같은 폴더의 `.SIU-backup-UUID.app`에 보존. 교체/재실행 명령 실패 시 기존 앱 보존 또는 복원. 다운로드/검증 실패 시 기존 앱을 변경하지 않음.
- 자동 업데이트는 Homebrew 실행 없이 동작하며 Homebrew 설치 기록은 갱신하지 않음. 현재 버전은 앱 Info.plist로 확인. 미공증·ad-hoc 서명 베타이며 Apple Developer 서명 기반 배포 인증은 아직 아님.
- macOS 13 이상 / Apple Silicon·Intel 유니버설. 앱 실행에 Xcode·CLT 불필요. 누끼 추출 스크립트만 macOS 14 이상 필요.
- 1대1 프로토콜 13 / 2대2 프로토콜 3. 참가자 모두 같은 버전 필요.

## 검증

유니버설 빌드와 코드서명 검증, 물리/스태미나/태클 테스트, 로컬 TCP 4클라이언트 진영 동기화·경기·패스·일시정지·연결 종료 테스트. 자동 업데이트 SHA256/압축 경로 검사, 임시 앱 교체·백업 보존·잘못된 버전과 외부 심볼릭 링크 거부 회귀 테스트. 실제 다른 Mac 4대 와이파이 대전과 미래 공개 릴리스로의 자동 업데이트는 별도 실기기 확인 필요.

## 설치/이 버전으로 업데이트

이전 버전의 팝업은 Homebrew 명령 복사 방식이다. **이번 버전을 한 번 설치한 뒤부터** 새 자동 업데이트가 동작한다.

```bash
brew update
brew upgrade --cask ddingddong9/siu/siu-app-beta
open /Applications/SIU.app
```
