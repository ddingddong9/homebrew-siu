# SIU 1.14.0 beta 1

- 백숏은 슛이 아닌 급방향 전환: 공 소유 유지, 뒤로 당기기, 180° 회전.
- 홈에 4인 LAN 2대2 추가. Mac 4대, 각자 한 선수, 방장 승인과 고정 참가 순서 팀 배정.
- 빨강 2명·파랑 2명 유니폼, 선수 번호와 나 표시. 기존 누끼 선수 이미지 유지.
- 2대2 경기 공간 약 20% 확대, 기본 창 1320×840, 3분 경기.
- S 동료 패스, W 이동 방향 선행 스루패스, E 달리기.
- Shift+Q 백숏 / Shift+E 발재간 / Shift+X 사포 (SIU 간소화 키).
- 감아차기 강화: 큰 초기 옆 궤적 이후 골문을 향해 강하게 휘는 비현실적인 바나나 슛. 수비 접촉 시 유도 해제.
- 1대1 기존 조작 유지, 프로토콜 11. 같은 앱 버전 필요.
- 호스트 권위 물리와 점수, 네 선수 입력, 상태 20Hz 전달, 연결 끊김 시 중단.

설치·업데이트·재설치·버전 확인은 저장소의 `BREW_GUIDE.md` 참고.

```bash
brew update
brew upgrade --cask ddingddong9/siu/siu-app-beta
```

macOS 13 이상, Apple Silicon·Intel 공용. SIU 실행에는 Xcode/CLT 불필요. Homebrew 최초 설치 과정에서는 CLT를 요구할 수 있음. ad-hoc 서명·미공증 베타.

자동 검증: 물리, 백숏 소유 유지, 동료 패스·스루패스, 4인 루프백 TCP, 슬롯 배정, 입력·상태 전달, 일시정지, 연결 종료, 71개 투명 개인기 프레임. 실제 서로 다른 Mac 4대 검증은 아직 미완료.
