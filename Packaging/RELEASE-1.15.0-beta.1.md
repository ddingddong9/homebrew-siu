# SIU 1.15.0 beta 1

- 1대1·2대2 태클을 전방 대시 슬라이딩으로 변경. 0.55초 동안 감속 이동하며 공·상대 접촉을 계속 판정.
- 태클 방향 고정, 1.15초 재사용 제한, 슬라이딩 중 슛·개인기 중복 방지.
- 달리기 스태미나 100. 이동하며 달릴 때 초당 24 소모, 걷거나 쉬면 초당 15 회복.
- 소진 시 20 이상 회복한 뒤 재달리기. 선수 아래 녹색·주황색 게이지 표시.
- 1대1은 Shift 달리기, 2대2는 E 달리기. A는 두 모드 모두 슬라이딩 태클.
- 2대2 스태미나·태클·피격은 방장 계산 후 동기화. 1대1은 기존 로컬 이동 방식 유지, 상대 스태미나 전달과 방장 충돌 판정.
- 1대1 프로토콜 12, 2대2 프로토콜 2. 참가자 모두 같은 버전 필요.
- 기존 바나나 슛·개인기·대기 호날두 아이콘 유지.

```bash
brew update
brew upgrade --cask ddingddong9/siu/siu-app-beta
```

자동 테스트: 소모·회복·소진 재진입, 슬라이딩 거리·감속·쿨다운, 이동 도중 공·상대 접촉, 연속 접촉 경로, 4인 TCP 스태미나 전달, 기존 물리·통신·이미지 검사. 실제 Mac 4대 검증은 별도.
