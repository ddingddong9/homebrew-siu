# 메시 원본 누끼

2026-10-07 사용자가 기본 사진과 슛·태클·팬텀 GIF를 제공하고 사용·공개 배포 권한을 확보했다고 확인했다. 원본은 Downloads에 있으며 저장소에 원본 전체 영상을 재배포하지 않는다. 결과물은 `Sources/MacArrow/Resources/messi-*.png` 51개다.

재현: `swift Scripts/extract-messi.swift idle|shot|tackle|phantom INPUT OUTPUT_DIR` (macOS 14+ Vision). 원본 프레임을 크롭하고 Vision 전경 인스턴스에서 메시를 선택, 다른 분리된 조각과 별도 게임 공에 해당하는 원본 영역을 제거한다. 가려진 신체를 생성하거나 복원하지 않는다. preview 4장 시트는 `/tmp/messi-KIND-cutouts.png`에 생성된다.

기본 1장, 슛 0...22(23장), 태클 8...27(20장), 팬텀 0...6(7장). 팬텀 뒤 구간은 상대와 겹쳐 제외했다. 태클은 원본부터 일부 팔/발이 화면 밖인 구간과 모션 블러가 있다. 기본은 아르헨티나 유니폼, 동작은 바르셀로나 유니폼이며 제공 자료를 그대로 유지한다. 팀은 이름/색상 표시로 구별한다.

추가 필요: 자연스러운 걷기·달리기 루프(가능하면 정면/측면/후면), 세레머니, 발재간, 급방향전환 백숏, 사포. 전신이 화면 안에 있고 다른 선수와 겹치지 않는 GIF/영상이 적합하다. 자료가 없는 동작은 메시 기본 자세와 공 효과로 표시한다.
